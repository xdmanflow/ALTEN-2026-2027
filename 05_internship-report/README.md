## Writing tips

- Fill the weekly highlights section of the outline **every Friday** — it makes the final writing much easier.
- For each mission: **context → problem → approach → results → impact → limits**.
- Quantify results whenever allowed (time saved, accuracy reached, number of dashboards delivered).
