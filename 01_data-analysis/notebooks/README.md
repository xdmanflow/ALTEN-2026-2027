# Notebooks

All notebooks run on **synthetic data** only.

```bash
python generate_synthetic_data.py      # creates synthetic/interviews.csv
jupyter notebook 01_cleaning_and_kpis.ipynb
```

| Notebook | Purpose |
|---|---|
| `generate_synthetic_data.py` | Generates a fake recruitment dataset matching the [data dictionary](../docs/data-dictionary.md) |
| `01_cleaning_and_kpis.ipynb` | Cleaning pipeline and KPI computation template |
