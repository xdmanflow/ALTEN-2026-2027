# Mission 1 — Recruitment Data Analysis

> Turning recruitment activity data into actionable insights for stakeholders.

## Objective

Answer concrete business questions about recruitment activity (volume, candidate quality, conversion, sourcing) through clean data, well-defined KPIs and clear dashboards.

## Workflow

1. **Ask** — define the business questions with stakeholders
2. **Collect** — export data from recruitment tools
3. **Clean** — apply tidy data principles (see [`docs/methodology.md`](docs/methodology.md))
4. **Analyze** — compute KPIs (see [`docs/kpi-definitions.md`](docs/kpi-definitions.md))
5. **Visualize** — build dashboards
6. **Communicate** — present insights and recommendations
